# Upstream sources

Use upstream sources to verify framework defaults, APIs, threat models, and tool semantics. Do not import their checklists wholesale or substitute them for target-specific data-flow analysis.

## Common methodology

- [Cloudflare security-audit skill](https://github.com/cloudflare/security-audit-skill) — phased reconnaissance, hunting, adversarial validation, reporting, and independent verification.
- [OWASP Cheat Sheet Series](https://github.com/OWASP/CheatSheetSeries) — vulnerability-class and control references.
- [OWASP Application Security Verification Standard](https://github.com/OWASP/ASVS) — coverage planning and control vocabulary.

Each stack module contains its own language and framework sources.
